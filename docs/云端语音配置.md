# 云端语音配置

游戏中的 AI 玩家公开发言、遗言和主持人公开公告均可自动播报。私密身份、狼人夜间消息和上帝视角日志不会播报。

## 推荐方式：后端环境变量保存密钥

先停止旧后端，再在启动后端的同一个 PowerShell 窗口中设置环境变量。

### OpenAI TTS 或 OpenAI 兼容服务

```powershell
$env:VOICE_OPENAI_API_KEY = '你的 API Key'
$env:VOICE_OPENAI_BASE_URL = 'https://api.openai.com/v1/audio/speech'
mvn.cmd -f backend/pom.xml spring-boot:run
```

在“语音配置”页面选择：

1. 语音引擎：`云端语音`
2. 云端服务：`OpenAI / OpenAI Compatible`
3. API 地址和 API Key：均可留空，使用后端环境变量
4. 模型：`gpt-4o-mini-tts`
5. 玩家音色：例如 `alloy` 或 `nova`
6. 主持人音色：例如 `onyx` 或 `coral`
7. 点击“测试语音”，成功后保存配置

使用其他 OpenAI 兼容 TTS 服务时，将 `VOICE_OPENAI_BASE_URL` 改为服务商给出的 `/v1` 或 `/audio/speech` 地址，并在页面中填写其模型和音色名称。

### Azure Speech

```powershell
$env:VOICE_AZURE_API_KEY = '你的 Azure Speech Key'
$env:VOICE_AZURE_BASE_URL = 'https://eastasia.tts.speech.microsoft.com/cognitiveservices/v1'
mvn.cmd -f backend/pom.xml spring-boot:run
```

将 `eastasia` 替换成 Azure 资源的实际区域。在“语音配置”中选择 `Azure Speech`，API 地址和 Key 可留空。推荐中文音色：

- 主持人：`zh-CN-XiaoxiaoNeural`
- 男玩家：`zh-CN-YunxiNeural`
- 男主持或强势角色：`zh-CN-YunjianNeural`

## 页面临时配置

也可以直接在“语音配置”页面填写 API 地址和 API Key。密钥只会发送到本项目的后端代理：

- 不勾选“在此浏览器长期记住 API Key”：密钥仅保存在当前浏览器标签页的会话存储中，关闭标签页后清除。
- 勾选后：密钥保存在当前浏览器的本地存储中，仅适合个人电脑和本地开发环境。
- 部署到公网时应使用后端环境变量，并给 `/api/voice/**` 增加登录鉴权和调用限流。

## 启动前端

```powershell
npm.cmd --prefix frontend run dev
```

打开前端后进入“语音配置”。页面右上角显示“云端代理可用”，云端卡片显示“服务端密钥已配置”时，说明后端配置已经生效。

## 播放和回退规则

- 语音按消息产生顺序串行播放，主持人连续公告不会互相覆盖。
- 暂停游戏会同时暂停当前语音，继续游戏后恢复。
- 玩家和主持人可以设置不同音色。
- 云端请求默认超时为 30 秒；OpenAI 模式可选 `MP3/WAV/OPUS`，Azure 原生模式可选 `MP3/WAV/OGG`。
- 开启“云端调用失败时自动回退”后，网络或额度异常时继续使用浏览器本机语音。
- 浏览器通常要求用户先点击页面后才允许播放音频，首次使用请先在配置页点击“测试语音”。

## 常见问题

- `云端代理不可用`：后端未启动、仍是旧进程，或前端连接的不是 `http://localhost:8081/api`。
- `服务端密钥未配置`：环境变量没有在启动后端的同一个终端中设置；停止后端并重新设置、启动。
- `401/403`：API Key 无效、权限不足或服务商账户没有 TTS 权限。
- `404`：API 地址不正确。OpenAI 兼容地址应指向 `/v1` 或完整的 `/audio/speech`。
- 有文字但没有声音：先点击“测试语音”解除浏览器自动播放限制；云端失败时检查后端日志。
